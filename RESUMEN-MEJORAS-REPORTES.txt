───────────────────────────────────────────────────────────────
  MEJORA #1: MODAL DE ADVERTENCIA EMERGENTE
───────────────────────────────────────────────────────────────

✅ QUÉ HACE:
   Muestra un diálogo modal ANTES de generar cada reporte con
   información clara sobre la expiración a 30 días

✅ CÓMO FUNCIONA:
   1. Usuario configura el reporte (tipo, fechas)
   2. Click en "Generar Reporte"
   3. Sistema valida los datos
   4. → APARECE MODAL DE ADVERTENCIA ←
   5. Usuario confirma o cancela
   6. Si confirma → Genera el reporte

✅ INFORMACIÓN MOSTRADA:
   • ⚠️ Advertencia destacada
   • 📅 Fecha exacta de expiración (30 días)
   • 💡 Recomendaciones específicas
   • ✓ Botón claro de confirmación

✅ VENTAJAS:
   ✓ No se puede ignorar (modal bloqueante)
   ✓ El usuario está informado SIEMPRE
   ✓ Reduce sorpresas ("¿por qué se borró?")
   ✓ Fomenta descargas inmediatas

✅ CARACTERÍSTICAS DE CADA CARD:

   1. ICONO GRANDE Y DISTINTIVO
      📈 Ventas, 📦 Inventario, 💰 Gastos, etc.

   2. NOMBRE CLARO
      "Ventas", "Inventario", "Gastos"...

   3. DESCRIPCIÓN ÚTIL
      Explica qué información incluye

   4. COLOR ÚNICO
      🟢 Verde = Ventas
      🔵 Azul = Inventario
      🔴 Rojo = Gastos
      🟣 Morado = Cierres
      🟡 Ámbar = Financiero

   5. CHECKMARK CUANDO ESTÁ SELECCIONADO
      ✓ Visible en la card activa

   6. ANIMACIONES
      • Hover: Escala ligeramente
      • Click: Feedback táctil
      • Selección: Resaltado con gradiente

───────────────────────────────────────────────────────────────
  LOS 5 REPORTES OPTIMIZADOS PARA TENDEROS
───────────────────────────────────────────────────────────────

1. 📈 REPORTE DE VENTAS
   Para: Saber cuánto se vendió y por qué método
   Incluye: Total, métodos de pago, top productos

2. 📦 REPORTE DE INVENTARIO
   Para: Revisar stock y productos por vencer
   Incluye: Alertas, valor total, utilidad potencial
   Nota: No requiere período (instantáneo)

3. 💰 REPORTE DE GASTOS
   Para: Controlar en qué se está gastando
   Incluye: Total por categoría, promedios

4. 🏦 REPORTE DE CIERRES DE CAJA
   Para: Auditar arqueos y diferencias
   Incluye: Faltantes, sobrantes, métodos de pago

5. 💼 RESUMEN FINANCIERO
   Para: Ver rentabilidad general
   Incluye: Ingresos vs gastos, utilidad neta, margen

───────────────────────────────────────────────────────────────
  FLUJO MEJORADO COMPLETO
───────────────────────────────────────────────────────────────

PASO 1: SELECCIONAR TIPO
   • Visualiza las 5 cards
   • Click en la deseada (ej: Ventas)
   • Ve checkmark de confirmación ✓

PASO 2: CONFIGURAR PERÍODO (si aplica)
   • Click en período rápido: "Última Semana"
   • O selecciona fechas manualmente
   • Ve resumen: "📊 8 días seleccionados"

PASO 3: GENERAR (CON VALIDACIÓN)
   • Click en "Generar Reporte de Ventas"
   • Sistema valida fechas automáticamente
   • Si hay error → Toast inmediato
   • Si todo OK → Continúa

PASO 4: CONFIRMAR (MODAL EMERGENTE)
   • ⚠️ Aparece modal de advertencia
   • Muestra fecha de expiración
   • Usuario lee y confirma
   • O cancela y vuelve atrás

PASO 5: DESCARGAR
   • Reporte generado aparece en "Mis Reportes"
   • Botones: PDF / Excel / Eliminar
   • Barra de progreso de expiración
