  🛠️ SOLUCIÓN DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════

Error: "Cannot find module X"
→ Solución: npm install

Error: "Port 5173 already in use"
→ Solución: Cerrar proceso en puerto 5173 o cambiar puerto en vite.config.ts

Error: Vite no inicia
→ Solución: 
  1. npm run clean
  2. rm -rf node_modules
  3. npm install
  4. npm run dev

Error: Build falla
→ Solución:
  1. npm run check:syntax
  2. npm run verify
  3. Corregir errores mostrados
  4. npm run build
