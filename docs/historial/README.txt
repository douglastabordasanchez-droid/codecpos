🎨 SISTEMA DE LOGOS
════════════════════════════════════════════════════════════════════════

Pon tus logos SOLO en /public/:

  /public/
    ├── logo.png    (512×512 px, PNG transparente)
    └── icon.ico    (256×256 px, ICO o PNG)


El sistema usará SOLO estos archivos en:
  ✅ Página de bienvenida
  ✅ Página de login
  ✅ Dashboard
  ✅ Instalador
  ✅ Ícono del programa
