  🎓 INFORMACIÓN TÉCNICA
═══════════════════════════════════════════════════════════════════════════════

  Problema del setInterval:
  ─────────────────────────

  ANTES (MALO):
  ─────────────
  useEffect(() => {
    const interval = setInterval(loadConfig, 1000);  // ❌ Cada segundo
    return () => clearInterval(interval);
  }, []);

  Problemas:
  • 60 ejecuciones por minuto
  • Re-renderiza constantemente
  • Bloquea inputs
  • Consume CPU


  AHORA (BUENO):
  ──────────────
  useEffect(() => {
    loadConfig();  // Solo una vez al inicio
    
    window.addEventListener('storage', handleStorageChange);  // Solo si cambia
    
    return () => {
      window.removeEventListener('storage', handleStorageChange);
    };
  }, []);

  Beneficios:
  • 0 ejecuciones si no hay cambios
  • No bloquea nada
  • Rendimiento óptimo
  • Mejor UX


  Configuración del Toaster:
  ──────────────────────────

  ANTES (MALO):
  ─────────────
  <Toaster position="top-right" richColors />
  
  Problema:
  • Sin duration → Se quedan para siempre


  AHORA (BUENO):
  ──────────────
  <Toaster 
    position="top-right" 
    richColors 
    duration={3000}       // 3 segundos
    closeButton           // Botón X
    expand={false}        // No expandir
    visibleToasts={3}     // Máximo 3
  />

  Beneficio:
  • Se ocultan automáticamente
