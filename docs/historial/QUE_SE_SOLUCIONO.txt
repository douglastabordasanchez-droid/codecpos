CAUSA DEL PROBLEMA
════════════════════════════════════════════════════════════════════════

Los modulos nativos (.node) de Node.js no estaban siendo
empaquetados correctamente por electron-builder. Estos modulos
necesitan tratamiento especial:

  • serialport
  • @serialport/bindings-cpp
  • usb
  • bindings
  • node-gyp-build


LO QUE SE CORRIGIO
════════════════════════════════════════════════════════════════════════

1. ✅ electron/builder-config.js
   - Agregada exclusion de TODOS los archivos .node
   - Mejorado asarUnpack para modulos nativos
   - Optimizados filtros de archivos

2. ✅ scripts/clean-build.js (NUEVO)
   - Limpieza automatica antes de compilar
   - Elimina dist/, dist-electron/, .vite/
   - Evita conflictos de builds anteriores

3. ✅ package.json
   - Todos los scripts ahora limpian automaticamente
   - npm run compile = limpieza + build + instalador
   - Proceso mas robusto

4. ✅ COMPILAR_LIMPIO.bat (NUEVO)
   - Archivo .bat mejorado
   - Incluye limpieza automatica
   - Mensajes mas claros
