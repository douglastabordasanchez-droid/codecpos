═══════════════════════════════════════════════════════════════════════════════
  🎯 ¿CUÁNDO SE CREA?
═══════════════════════════════════════════════════════════════════════════════

El usuario Admin se crea AUTOMÁTICAMENTE cuando:

1. Instalas el .exe por PRIMERA VEZ
2. La aplicación detecta que NO HAY usuarios guardados
3. Crea el usuario Admin con la contraseña arriba indicada
4. Lo guarda en las 3 capas de persistencia:
   • IndexedDB (base de datos en navegador)
   • localStorage (almacenamiento rápido)
   • Archivo JSON en disco: %APPDATA%\codec-pos\CODEC_POS_Data\usuarios.json


═══════════════════════════════════════════════════════════════════════════════
  💾 ¿DÓNDE SE GUARDA?
═══════════════════════════════════════════════════════════════════════════════

Ruta en Windows:

    C:\Users\[TuNombreDeUsuario]\AppData\Roaming\codec-pos\CODEC_POS_Data\
      ├── usuarios.json          ← Archivo principal
      └── usuarios_backup.json   ← Backup automático


Este archivo PERSISTE entre sesiones, por lo que:

    ✅ Los usuarios NUNCA se pierden al cerrar el .exe
    ✅ Los usuarios se mantienen después de reiniciar Windows
    ✅ Los usuarios sobreviven actualizaciones del software
    ✅ Hay backup automático por si algo falla


═══════════════════════════════════════════════════════════════════════════════
  🚀 CÓMO USAR
═══════════════════════════════════════════════════════════════════════════════

PASO 1: Compilar el .exe
────────────────────────────────────────────────────────────────────────────
    npm run compile

    Esto generará el instalador en:
    dist-electron/CODEC POS Setup [versión].exe


PASO 2: Instalar en el equipo de producción
────────────────────────────────────────────────────────────────────────────
    • Ejecuta el instalador .exe
    • Sigue el wizard de instalación
    • El software se instalará en: C:\Program Files\CODEC POS\


PASO 3: Primer inicio
────────────────────────────────────────────────────────────────────────────
    1. Inicia CODEC POS desde el escritorio o menú inicio
    2. Aparecerá la pantalla de LOGIN
    3. Ingresa:
       Usuario:     Admin
       Contraseña:  Noruega2025++*
    4. ¡Listo! Estás dentro del sistema


PASO 4: Crear usuarios adicionales
────────────────────────────────────────────────────────────────────────────
    1. Ve a: Configuración → Usuarios
    2. Click en "Nuevo Usuario"
    3. Completa el formulario:
       • Nombre completo
       • Cédula (código de empleado)
       • Usuario (login)
       • Contraseña
       • Rol (Super Usuario o Cajero)
       • Permisos (para cajeros)
    4. Click en "Guardar"
    5. El usuario se guarda AUTOMÁTICAMENTE en las 3 capas

  🐛 PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════════════

❌ "No puedo hacer login con Admin"
────────────────────────────────────────────────────────────────────────────
    La contraseña es: Noruega2025++*
    
    • Verifica que usas MAYÚSCULAS y minúsculas correctas
    • Incluye los caracteres especiales: ++*
    • NO copies y pegues, escríbela manualmente


❌ "Los usuarios se pierden al cerrar el .exe"
────────────────────────────────────────────────────────────────────────────
    1. Abre DevTools (F12 en el .exe)
    2. Ve a la pestaña Console
    3. Busca: "✅ [Electron] Usuarios guardados"
    4. Si NO aparece, contacta soporte técnico


❌ "Error: electronAPI is not defined"
────────────────────────────────────────────────────────────────────────────
    El preload.cjs no se cargó correctamente.
    
    Solución:
    1. Borra la carpeta: dist-electron/
    2. Recompila: npm run clean && npm run compile
