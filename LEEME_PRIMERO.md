## ❓ **PREGUNTAS RÁPIDAS:**

### **¿Por qué tengo que desactivar el antivirus?**

```
Windows Defender está bloqueando app-builder.exe
(parte de electron-builder) porque lo marca como
"amenaza potencial".

app-builder.exe es 100% SEGURO, pero Windows
no lo reconoce porque se descarga dinámicamente.

Desactivarlo temporalmente soluciona el problema.
```

---

### **¿Es seguro desactivar Windows Defender?**

```
✅ SÍ, si es solo por 30-40 minutos
✅ SÍ, si no navegas por internet durante ese tiempo
✅ SÍ, si lo reactivas inmediatamente después

Windows lo reactivará automáticamente en 10-15 minutos
si no lo haces tú.
```

---

### **¿Cuántas veces tengo que hacer esto?**

```
SOLO UNA VEZ por compilación.

Si después quieres recompilar, tendrás que
repetir el proceso (desactivar → compilar → reactivar).

PERO: Una vez que tengas el instalador .exe,
ya no necesitas compilar de nuevo a menos que
hagas cambios en el código.
```
