🎨 PASO 1: PON TUS LOGOS
════════════════════════════════════════════════════════════════════════

Copia tus archivos a /public/:

  /public/
    ├── logo.png    (512×512 px mínimo, PNG transparente)
    └── icon.ico    (256×256 px, ICO o PNG)

IMPORTANTE:
• El sistema usará SOLO estos archivos
• NO pongas logos en otras carpetas
• Si no pones logo.png, usará un SVG profesional
• Lee: SISTEMA_DE_LOGOS.md para más info


⚡ PASO 2: COMPILAR INSTALADOR (ULTRA SIMPLE)
════════════════════════════════════════════════════════════════════════

Método 1 (VS Code - RECOMENDADO):
─────────────────────────────────
1. Abre VS Code en esta carpeta
2. Presiona: Ctrl + ñ (abre terminal)
3. Escribe: npm run compile
4. Presiona ENTER
5. Espera 20 minutos
6. LISTO ✅


Método 2 (.bat):
───────────────
1. Doble click en: COMPILAR_LIMPIO.bat
2. Click derecho → Ejecutar como administrador
3. Sigue los pasos
4. Espera 20 minutos
5. LISTO ✅


Método 3 (Tareas VS Code):
─────────────────────────
1. Ctrl + Shift + P
2. Escribe: Tasks: Run Task
3. Selecciona: 🚀 COMPILAR TODO
4. Espera 20 minutos
5. LISTO ✅

⚠️ ANTES DE COMPILAR
════════════════════════════════════════════════════════════════════════

1. Pon tus logos en /public/
   • logo.png (512×512 px mínimo)
   • icon.ico (256×256 px)

2. Desactiva Windows Defender
   Windows + I → Seguridad → Protección contra virus → OFF

3. Verifica espacio en disco
   Mínimo 3 GB libres

4. Ejecuta como Administrador


🚀 MÉTODO MÁS RÁPIDO
════════════════════════════════════════════════════════════════════════

Abre VS Code → Terminal → Escribe:

   npm run compile
